# Что предсказывается по антропометрии: процент жира, калории и занятия спортом (NHANES)

Исследовательский проект на открытых данных NHANES (CDC, США, 2011-2018). Я проверяю, что можно предсказать по возрасту, полу, росту, весу и обхватам талии и плеча: физиологический показатель (процент жира) или поведение (рацион, занятия спортом).

## Главные выводы

- **Процент жира предсказывается хорошо.** CatBoost на отложенной выборке: MAE 2.7 п.п., R² 0.84. Простое среднее даёт MAE 7.25 п.п. Основной вклад вносят пол, обхват талии, ИМТ и рост.
- **Калории по телосложению почти не предсказываются.** MAE 639 ккал против 677 у медианного прогноза, R² не выше 0.1. Данные о питании получены из одного 24-часового опроса, поэтому шум в них большой.
- **Занятия интенсивным спортом по антропометрии предсказываются слабо.** ROC-AUC около 0.7 при 0.5 у случайной модели. Признак, собранный из ответов того же опросника, поднимает AUC до 0.95. Это утечка таргета, а не качество модели.

## Данные

Источник: [NHANES](https://wwwn.cdc.gov/nchs/nhanes/), циклы 2011-2012, 2013-2014, 2015-2016 и 2017-2018 (буквы G, H, I, J в именах файлов).

| Файл | Что берётся |
|------|-------------|
| DEMO | возраст, пол |
| BMX | рост, вес, ИМТ, обхват талии, обхват плеча |
| DXX | процент жира всего тела (DXA) |
| DR1TOT | калории, белки, жиры, углеводы за первый день опроса о питании |
| PAQ | анкета о физической активности |

Подготовка данных:

- таблицы объединены по идентификатору участника (SEQN);
- удалены записи, где заявленная калорийность расходится с расчётной по БЖУ (4/4/9 ккал на грамм) больше чем на 500 ккал;
- оставлены взрослые (от 18 лет) с суточной калорийностью от 1000 до 6000 ккал;
- удалены строки с пропусками в ключевых колонках (в обхвате талии и плеча их меньше 1%);
- служебные коды анкеты (отказ, «не знаю») заменены на пропуски, а пропуски в вопросах о днях и минутах активности заполнены нулями, то есть отказ от ответа считается отсутствием активности;
- из ответов анкеты рассчитаны признаки `work`, `walk` и `sport` (среднее число минут активности в день, интенсивные нагрузки учтены с коэффициентом 1.5).

## Методика

- Модели: CatBoost и линейная регрессия. Для сравнения использованы прогнозы «всем среднее» и «всем медиана».
- Гиперпараметры заданы заранее и не подбирались.
- Выбор набора признаков для модели жира: кросс-валидация 5 фолдов × 3 повтора (RepeatedKFold).
- Итоговая модель жира: разбиение на обучающую, валидационную (ранняя остановка CatBoost) и тестовую выборки. Метрики посчитаны на тесте.
- Метрики: MAE, R² (регрессия), ROC-AUC, accuracy, матрицы ошибок (классификация).
- Интерпретация итоговой модели: SHAP.

## Результаты

### 1. Выбор набора признаков для процента жира

CatBoost, MAE в процентных пунктах жира, кросс-валидация. Разброс между проверками составляет около 0.04-0.05.

| Набор признаков | MAE |
|-----------------|-----|
| База (пол, возраст, рост, вес, ИМТ) | 2.952 |
| База + КБЖУ | 2.929 |
| База + активность | 2.870 |
| База + талия, плечо | 2.597 |
| База + талия, плечо + КБЖУ | 2.594 |
| База + талия, плечо + активность | 2.571 |

Талия и обхват плеча дают прирост в 0.355, примерно в восемь раз больше разброса. Питание и активность укладываются в один-два разброса, поэтому отличить их эффект от случайных колебаний нельзя. Для итоговой модели выбран набор «База + талия, плечо». CatBoost лучше линейной регрессии на всех наборах на 6-10%.

### 2. Итоговая модель процента жира (тестовая выборка)

| Модель | MAE | R² |
|--------|-----|----|
| Среднее значение | 7.25 | - |
| Линейная регрессия | 2.969 | 0.815 |
| CatBoost | 2.715 | 0.843 |

По SHAP сильнее всего на прогноз влияет пол (около ±5 п.п.), затем обхват талии, ИМТ и рост. Вес вносит небольшой вклад, потому что дублируется ростом и ИМТ.

### 3. Калории (тестовая выборка)

| Модель | MAE, ккал | R² |
|--------|-----------|----|
| Среднее значение | 690 | - |
| Медиана | 677 | - |
| Линейная регрессия | 643 | до 0.1 |
| CatBoost | 639 | до 0.1 |

### 4. Занятия интенсивным спортом

Таргет: ответ на вопрос PAQ650 (самоотчёт об интенсивной физической нагрузке). Он не отражает объём тренировок и не равен статусу спортсмена. Доля положительного класса около одной трети, поэтому прогноз «всем нет» даёт accuracy около 0.67.

| Набор признаков | ROC-AUC | Accuracy |
|-----------------|---------|----------|
| Антропометрия (и с добавлением КБЖУ, процента жира, работы и прогулок) | 0.69-0.70 | 0.695-0.710 |
| Антропометрия + `sport` | 0.952 | 0.880 |

Скачок на последней строке объясняется утечкой: `sport` собран из ответов на вопросы о том же виде нагрузки, что и PAQ650, поэтому почти дублирует таргет.

## Ограничения

- Данные о питании это один 24-часовой опрос, а не привычный рацион. Он содержит много шума, что объясняет слабое качество прогноза калорий.
- Физическая активность это самоотчёт. Отказы от ответа в анкете считаются нулевой активностью.
- Веса выборки NHANES не использовались, поэтому результаты нельзя переносить на всё население США.
- DXA-обследование проходили не все участники, поэтому в итоговую выборку попала только часть записей.
- Набор признаков выбран по кросс-валидации на той же выборке, из которой затем отложен тест. Оценка на тесте может быть чуть оптимистичнее, чем на новых данных.
- Все сравнения проведены с фиксированными гиперпараметрами и одним разбиением на тест.

## Как запустить

1. Скачайте с сайта NHANES файлы DEMO, BMX, DXX, DR1TOT и PAQ за циклы G, H, I, J (формат XPT) и положите их в папку рядом с ноутбуком. В коде имена файлов написаны как `DEMO_G.xpt`, `BMX_G.xpt` и так далее.
2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

3. Откройте `nhanes_analysis.ipynb` и выполните ячейки сверху вниз.
